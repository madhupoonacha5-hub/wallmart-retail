Model and architecture
  • The forecast carries a first-in, first-out workload across eight 30-minute intervals. Productive capacity is scheduled specialists × (1 − shrinkage) ÷ average handle time. SLA uses all human-queue demand as the denominator, including work still waiting at the horizon.
  • Incident demand falls once a modeled fix is ready. Guided recovery removes only eligible cases assumed to be verified without a handoff. Failed and uncertain cases retain a human workload.
  • The reference for released hours is fix-only under the same assumptions. Dollar figures use a $32 hourly scheduled staffing cost and a $48 hourly flex cost. Removing overtime from a plan only avoids spend if the shift can actually be canceled.
  • Simulation uses isolated mock actions. A production design would use permission checks, approval, idempotent execution, independent destination read-back and an action audit.
